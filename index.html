Git Version Checker

Interfaz simple para comprobar estado de git en el repo local 
Presiona un botón para consultar git...
Este frontend consulta endpoints locales que ejecutan comandos git en el directorio del servidor.
No expongas este servidor públicamente. Requiere Node.js y git instalados en la máquina que ejecuta el servidor.
Endpoints:
 - GET /api/status     -> git status --porcelain
 - GET /api/log        -> git log --oneline -n 20
 - GET /api/branches   -> git branch --list --verbose
Ejecuta npm install y luego node server.js. Abre http://localhost:3000
